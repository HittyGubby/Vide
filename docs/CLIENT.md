# 客户端

Vide 的权限按“是否登录”判断，桌面能力按“是否 Tauri”判断。

## 1. Tauri 本地

启动：

```bash
bun run tauri dev
```

- 直接访问本地 SQLite
- 不经过 HTTP
- 不需要登录
- 本地 mpv 播放
- 库管理、缓存、插件、导入全部可用
- 桌面歌词、快捷键、通用设置可用

## 2. Tauri 远程

设置 → 远程连接。

### 游客远程

- 服务端 URL 填写完整
- 密码留空
- 只能只读浏览、搜索
- 播放控制、标签、库/缓存/插件/导入隐藏
- 需要公开媒体或登录后才能播放

### 登录远程

- 填服务端密码
- 保存 Bearer token + CSRF
- 自动恢复上次服务端和登录状态
- token 失效自动降级游客远程
- 远程设置里可以再次登录

播放位置：

- 服务端播放：服务端 mpv 出声
- 客户端播放：本地 mpv 拉取服务端媒体，带 Bearer

## 3. Web

由服务端同源提供：

```text
http://server:8080/
```

- 游客只读
- 右上角登录
- Cookie session + CSRF
- 自动恢复登录
- 浏览器播放使用 `<audio>`
- 登录后可切“浏览器 / 服务端”播放位置

## 设置可见性

游客：

- 外观
- 详情歌词样式
- 数据：导出

登录后：

- 库管理
- 缓存管理
- 插件管理
- 导入歌曲 / 导入设置
- 播放位置切换
- 标签/元数据编辑
- 下载

仅 Tauri：

- 通用
- 快捷键
- 桌面歌词
- 悬浮歌词样式
- 远程连接入口

## 下载

- Web：浏览器直接下载
- Tauri 远程：服务端 `/api/v1/download/:id`，本地保存
- Tauri 本地：复制本地文件/缓存
- 文件名默认按音频扩展名；缓存 `.media` 默认导出 `.mp3`

## 状态同步

- Tauri 本地：本地状态轮询
- Tauri 远程服务端播放 / Web 服务端播放：SSE `/api/v1/player/stream`
- Web 浏览器播放 / Tauri 远程客户端播放：本地播放器事件
